# ZWPACK 0201 Demo

这是一个无构建依赖的静态交互 Demo，用于审核第一阶段产品方向，不是生产刀版软件。

## 打开方式

直接双击 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 已实现

- 内/外尺寸界面（Demo 均按输入值生成）；
- 箱型选择（首期开放 0201，其他 FEFCO 箱型显示即将支持）；
- 新增参数化“握手榫锁翻盖盒”理论 Demo：中央锁舌/盒盖/后壁/盒底/前壁连续，左右带榫锁翼；
- L/W/H 实时变化；
- 接舌 G 可作为成箱参数单独调整；
- L/W/H 通过双向箭头直接标在展开面上；
- 上下摇盖总补偿 ΔF 可调整，默认示例 26.6 mm；
- 上下开槽使用 U 型圆弧封底刀线；
- 可一次上传多张 Logo/图片，在整张展开图范围内分别拖动并嵌入 SVG；
- 刀线、折线和尺寸箭头加粗；标尺数字会随画布和缩放比例逆向调整，保持可读；
- 按 `[(L+W)+8] × [(W+H)+4] × 2 ÷ 10000` 计算供应商计价面积（L/W/H 先换算为 cm，+8/+4 为修边计价放量）；
- 小/标准/大三级界面字号；
- B/E/C/AB/BC/EB 材料选择；
- 基于 Face、Shared Edge 语义的连续 0201 展开结构；
- SVG viewBox、刀线/压线、面标签、总展开尺寸；
- 滚轮缩放、拖动画布、适合画布；
- SVG 下载；
- 浏览器打印/另存 PDF；
- 理论预览和人工确认提示。

## Demo 假设

- 内/外尺寸转换暂时为 identity；
- 摇盖深度为 `W/2`；
- 粘合舌宽为 40 mm；
- 材料厚度和槽宽仅为界面示例值。

正式开发前必须由工厂确认并改为后台配置。本 Demo 不应输出给生产设备。
