# 珍珠棉专业设计台重构设计

## 目标

将现有珍珠棉分层 Demo 重构为同时服务业务人员、客户和工厂设计人员的专业二维设计工作台。系统采用“简洁模式 / 专业模式”双模式，共用同一套几何和图层数据，保证二维编辑、三维预览、属性输入和导出检查一致。

本阶段仍是可验证的设计 Demo，不直接生成生产设备数据，也不宣称内置间距、补偿或刀缝参数符合任何工厂标准。

## 用户与模式

### 简洁模式

面向业务人员和客户，保留成品尺寸、常用图形、图层选择、拖动、拉伸、三维预览和基础检查。隐藏高级节点、吸附设置、图形作用层范围和生产参数。

### 专业模式

面向工厂设计和打样人员，开放全部绘图工具、快捷键、节点编辑、图形作用层范围、吸附设置、图层管理和生产检查。

两种模式只改变界面复杂度，不复制或转换设计数据。用户可以随时切换模式而不丢失内容。

## 工作区信息架构

采用专业 CAD 工作台布局：

- 顶部栏：项目名称、模式切换、撤销、重做、保存、导出。
- 左侧工具栏：选择、钢笔、矩形、圆形、多边形、直槽和标尺。
- 中央二维画布：主编辑区域，显示成品边界、当前层轮廓、图形、尺寸和吸附辅助线。
- 右侧属性栏：根据当前选择动态显示层属性、图形属性、位置、尺寸和作用层范围。
- 底部图层栏：显示所有粘合层，支持选择、排序、复制、隐藏、锁定和删除。
- 三维预览：作为可折叠面板读取二维数据，不长期挤占二维画布。

窄屏下不缩小桌面布局，而是将右侧属性栏和底部图层栏改为抽屉或折叠区域，保证画布仍有可用尺寸。

## 选择与鼠标交互

### 选择状态

系统区分当前层和当前图形。图层栏选择决定二维画布展示与编辑的层；画布单击决定当前图形。属性栏根据当前图形优先显示图形属性，没有图形选择时显示当前层属性。

### 移动与拉伸

- 拖动对象内部：移动对象。
- 拖动四角控制点：同时改变长和宽，对角保持固定。
- 拖动四边中点：只改变对应方向。
- 按住 `Shift`：锁定长宽比例。
- 按住 `Alt/Option`：以中心为基准向两侧缩放。
- 双击尺寸标注：直接输入精确尺寸。
- 拖动期间显示 L、W、X、Y 实时浮标。

默认控制点保持恒定屏幕尺寸，不随画布缩放变得过小或过大。层和图形不得越出所属边界；达到边界后停止，并给出非阻塞提示。

### 键盘操作

- 方向键：移动 1mm。
- `Shift + 方向键`：移动 10mm。
- `Esc`：取消当前绘制或拖动。
- `Delete/Backspace`：删除当前图形。
- `Cmd/Ctrl + Z`：撤销。
- `Cmd/Ctrl + Shift + Z`：重做。
- `Cmd/Ctrl + C/V/D`：复制、粘贴和原位复制。

文本输入获得焦点时，绘图快捷键暂停，避免误操作。

## 吸附与对齐

默认开启以下吸附：

- 成品和当前层边界。
- 水平与垂直中心线。
- 其他图形的节点、边中点和中心点。

网格吸附默认关闭，可在显示设置中开启。吸附容差按屏幕像素计算，因此画布缩放后操作手感保持一致。命中吸附时显示临时辅助线、目标点和距离提示。

属性栏提供水平左/中/右对齐、垂直上/中/下对齐。只有多个图形被选择时才显示图形间分布功能。

## 图层与图形数据模型

### 图层

每个图层保存：

- 稳定 ID。
- 名称。
- 长度、宽度和厚度。
- X/Y 平面位置。
- 堆叠顺序。
- 显示、锁定状态。

新增层默认继承成品长宽并居中。修改成品尺寸时，图层尺寸和位置按边界规则收敛，不进行不可逆的比例缩放。

### 图形

每个孔、槽或轮廓保存：

- 稳定 ID 和名称。
- 几何类型与节点。
- X/Y、长宽或包围盒。
- 工艺类型和切入深度。
- 作用层范围。

作用层范围支持：

- 仅当前层。
- 用户指定的多个层。
- 贯穿全部层。

独立图形属于某一层；多层或贯穿图形使用共享图形记录和层 ID 集合，避免多份副本修改后失去同步。

## 图层管理

- 点击图层切换当前层，二维画布立即显示该层尺寸和有效图形。
- 拖动图层卡片改变堆叠顺序，三维预览同步更新。
- 复制图层时复制其独立图形；共享图形保持共享关联。
- 锁定层后禁止画布修改，但仍可查看和测量。
- 隐藏层只影响工作区显示，不改变导出数据。
- 删除包含独立图形的层前显示明确确认；删除后共享图形从作用层集合中移除。

## 二维与三维数据流

二维设计数据是唯一事实来源。所有鼠标操作和属性输入先生成几何命令，经过边界与工艺验证后更新设计状态。二维画布、图层栏、属性栏、三维预览和检查面板订阅同一状态。

三维预览不保存另一份位置或尺寸，只根据图层顺序、图层几何和图形作用范围即时生成。这样可以避免二维和三维产生不一致。

## 历史、保存与恢复

所有改变设计含义的操作进入统一命令历史：

- 图层新增、删除、复制和排序。
- 图层与图形移动、拉伸和数值输入。
- 节点编辑。
- 图形作用层范围与切入深度修改。

连续拖动只在松开鼠标时形成一条历史记录。页面在本地自动保存草稿，重新打开后允许恢复。草稿必须包含模型版本，为后续数据迁移保留入口。

## 生产检查

检查器输出错误和警告两种级别：

### 错误

- 零尺寸或无效几何。
- 图层或图形越界。
- 切入深度超过作用层总厚度。
- 无法解析的自相交轮廓。

错误阻止导出。

### 警告

- 总层高与成品高度不一致。
- 孔距层边缘小于配置值。
- 图形之间间距小于配置值。
- 重叠或重复轮廓。

警告允许继续导出，但必须在导出确认中显示。间距、补偿、刀缝和压缩量均来自明确配置；没有工厂确认的值不得标记为生产标准。

## 错误处理

- 属性输入不合法时保留上一个有效值，并在字段旁显示具体原因。
- 拖动或拉伸触达边界时收敛到最大有效值，不抛出对话框。
- 几何运算失败时保留原始图形，标记检查错误，禁止导出。
- 本地草稿损坏或版本不兼容时不覆盖当前状态，提供忽略和导入诊断信息的选项。

## 可访问性与易用性

- 所有工具都有可见名称、图标和快捷键提示。
- 颜色状态同时使用边框、图标或文字，不只依赖颜色。
- 控制点和点击目标保持足够的屏幕尺寸。
- 键盘焦点可见，常用操作可在不使用鼠标时完成。
- 简洁模式使用业务语言；专业模式同时显示 L/W/H、X/Y 和工艺术语。

## 测试策略

### 几何单元测试

- 八方向拉伸的固定锚点。
- `Shift` 等比和 `Alt/Option` 中心缩放。
- 移动、缩放和属性输入的边界限制。
- 屏幕像素吸附向模型坐标的转换。
- 图层排序、复制、删除和共享图形范围。
- 切入深度和总层高检查。

### 状态与历史测试

- 每次操作只生成一条可撤销命令。
- 撤销和重做恢复完整模型。
- 简洁/专业模式切换不改变设计数据。
- 草稿序列化、恢复和模型版本处理。

### 集成与浏览器测试

- 画布拖动、八控制点拉伸和尺寸双击输入。
- 图层切换后二维画布与属性栏同步。
- 图形作用于当前层、多层和全部层。
- 二维修改后三维同步。
- 桌面工作区与窄屏抽屉布局。
- 键盘快捷键在画布和输入框中的冲突处理。

## 实施边界

首轮实施聚焦工作台布局、统一状态、图层独立图形、移动拉伸、属性同步、基础吸附、撤销历史和三维同步。生产设备格式、真实刀缝/补偿参数、云端项目协作、权限系统和正式报价流程不在本轮范围内。
