# ZWPACK 首页与在线工具专栏优化设计

## 目标

在不改变现有网址、后台数据结构、导航信息架构和业务内容的前提下，降低模板感，强化包装工厂的真实、专业与工程属性，并让首页到在线工具专栏保持一致体验。

## 设计判断

- 页面类型：面向企业采购、工程师与中小企业客户的 B2B 工厂官网。
- 模式：保留式优化，不做品牌推倒重来。
- 视觉语言：深海军蓝、冷灰纸张色、单一工业蓝强调色，使用真实产品图片和结构线作为视觉识别。
- 参数：DESIGN_VARIANCE 6，MOTION_INTENSITY 4，VISUAL_DENSITY 5。

## 首页

- 保留轮播数据和现有三个轮播内容。
- 首屏使用左侧文案、右侧真实背景视觉的非对称构图，标题最多两行，压缩副标题显示长度。
- 删除底部滚动鼠标动画。
- 产品区由四张等宽卡片改为一张主产品加三张次产品的不对称网格。
- 在线工具从优势区中拆出，形成独立横向结构功能带。
- 优势内容改成两列清单，以编号、标题和短说明构成，不再使用六张同质卡片。

## 在线工具专栏

- 保留 `/tools`、`/tools/carton-dieline`、`/tools/epe-designer` 路由。
- 工具专栏沿用首页的冷灰底、深蓝文字、工业蓝强调色和 14-16px 圆角。
- 轮播继续由用户主动切换，不增加自动播放。
- 每个工具使用真实 Demo 页面截图作为主视觉，不使用模拟界面。

## 约束

- 不改后台字段名称及 API。
- 不改产品、联系、关于我们的 URL。
- 不新增依赖。
- 不修改两个 Demo 的几何与交互逻辑。
- 本轮只制作本地预览，人工批准后才能部署。

## 验收

- 1440px 和 375px 均无横向溢出。
- 首页首屏按钮无需滚动即可看到。
- 首页所有 CTA 意图清楚且文字不换行。
- 首页与工具专栏看起来属于同一网站。
- 后台轮播内容仍可正常驱动 Hero。
